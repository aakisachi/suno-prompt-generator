# Sunoプロンプト生成

複数の曲（リリック・スタイル・タイトル）をSunoのAdvanced（旧Custom）モードへ順番に入力し、Createを押すChrome拡張機能です。

> [!IMPORTANT]
> 非公式ツールです。Suno, Inc.とは関係ありません。利用前にSunoの最新の利用規約を確認し、自分の責任で使用してください。

## 主な機能

- 複数の曲をキューへ追加（リリックのほか、スタイル・タイトルにも対応）
- トグルで入力する項目を切り替え
  - スタイル: 全曲共通の1つを使う／曲ごとに変える
  - タイトル: 曲ごとに入力する／Sunoの自動タイトルに任せる
  - 空欄の項目はSuno画面に入力済みの値をそのまま使用
- CSV読込
- 順次生成、停止、再開
- ポップアップを閉じた状態でのバックグラウンド実行
- 失敗した項目の再試行
- キューの一括削除
- 生成間隔の設定
- 各プロンプトの生成回数（1〜999回）— 同じ曲を続けて何回生成するか
- キューにマウスを乗せると詳細（タイトル・スタイル・リリック）を左側パネルに表示

## インストール

### ZIPを使う場合

1. GitHubの「Code」から「Download ZIP」を選びます。
2. ZIPを展開します。
3. Chromeで `chrome://extensions/` を開きます。
4. 右上の「デベロッパー モード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」を押します。
6. 展開したフォルダ内の `dist` フォルダを選びます。

### Gitを使う場合

```bash
git clone https://github.com/aakisachi/suno-prompt-generator.git
```

クローンしたフォルダ内の `dist` をChromeへ読み込んでください。

## 使い方

### 2.6.1への更新と待機停止からの復帰

- キューは削除せず、拡張機能を停止してから、現在読み込んでいるフォルダを新版の `dist` の内容で更新します。Chromeの拡張機能画面で「再読み込み」を押し、Sunoタブも再読み込みしてください。
- 次の実行時刻を端末に保存し、30秒ごとの監視でも確認します。次曲のアラームが途切れても、期限を過ぎた待機を再開します。Chromeの休止・スリープ中には監視も遅れるため、実時間の30秒以内を保証するものではありません。
- 入力要求の期限は45秒です。生成ボタンの許可前に応答が途切れた要求は失効させ、間隔を空けて最大2回再試行します。遅れて戻った要求は生成ボタンを押せません。
- 生成ボタンの直前に一度だけ使える許可を保存し、クリック後の確認を記録します。クリックされた可能性が残る場合は、自動再送せず「送信結果の確認が必要です」と表示します。
- この表示が出たら、Sunoの生成一覧で対象曲を確認し「送信済みを確認した」または「未送信を確認した」を選びます。古い入力を破棄するためSunoタブを再読み込みし、停止状態に戻ります。その後「再開」を押してください。
- 旧版の処理中だった曲は送信記録がないため、確認が必要です。既に完了した曲と生成回数は保持します。
- 「完了」はCreateのクリックを記録した状態です。Sunoの音源処理成功・課金・生成本数をAPIで確認する機能ではありません。CAPTCHAやサービス側の拒否を自動回避しません。

### 通常の操作

1. Chromeで `https://suno.com/create` を開き、Advanced（旧Custom）モードにします。
2. Chrome右上の拡張機能から「Sunoプロンプト生成」を開きます。
3. トグルで入力する項目（スタイル共通/曲ごと、タイトルあり/なし）を選びます。
4. 曲を貼り付けるか、CSVを読み込みます。
5. 「キューに追加」を押します。
6. 「開始」を押します。
7. 停止後に再開すると、未処理の曲から続けます。

開始後は拡張機能のポップアップを閉じても、別タブへ移動しても、Chromeを最小化しても処理が続きます。進捗は拡張機能アイコンのバッジ（数字表示）と、ポップアップ内のキューで確認できます。

### 貼り付け形式

**まるごと1曲（既定）** — 改行や空行を含む長文プロンプトを、そのまま貼るだけで1曲になります。設定の「改行を含めて1曲として扱う」がオンのときの動作です。

**1行1曲** — 上記トグルをオフにすると、1行ごとに別の曲として追加します。列はトグルに応じて変わり、順番はポップアップ内のヒントに表示されます。

```
朝のネオン,"80s city pop, warm bass","[Verse] 眠らない街を歩く"
```

**ブロック形式（複数行リリック向け）** — 曲を `---` で区切り、ラベルで指定します。

```
タイトル: 朝のネオン
スタイル: 80s city pop, warm bass
リリック:
[Verse]
眠らない街を歩く
---
タイトル: 雨のジャズ
スタイル: slow jazz
リリック:
[Verse]
窓の外は雨
```

**CSVファイル** — 1行目に `タイトル,スタイル,リリック`（必要な列だけでOK）の見出しを付けると、列名で読み取ります。旧形式の `曲名,プロンプト` も読み込めます。

スタイルやタイトルを空欄にした場合、Suno画面に入力済みの値がそのまま使われます。

## Chrome権限

| 権限 | 用途 |
| --- | --- |
| `storage` | キュー、進捗、生成間隔をChrome内へ保存するため |
| `activeTab` | 拡張機能を開いたSunoタブへ操作命令を送るため |
| `alarms` | ポップアップを閉じた後も次の曲を処理するため |
| `suno.com` / `app.suno.ai` | リリック・スタイル・タイトル入力欄とCreateボタンを操作するため |

この拡張機能は、外部の独自サーバーへデータを送信しません。アクセス先はSunoの対象ページに限定しています。解析ツールや広告も入れていません。

## 注意事項

- Sunoの表示言語は英語・日本語どちらにも対応しています（Lyrics editor / 歌詞エディタ、Song Title / 曲名、Styles / スタイル、Create / 作成）。
- Sunoの画面構成が変更されると、入力欄や作成ボタンを見つけられなくなる場合があります。
- CAPTCHA（人間確認）やアクセス制限を回避しません。表示された場合は停止します。
- Chromeを完全終了した場合やMacがスリープした場合は処理できません。Chrome再起動時にSunoタブが復元されていれば、保存済みのキューから再開します。
- 処理対象のSunoタブを閉じると、安全のためキューを一時停止します。
- 生成間隔は設定ボタンから10〜300秒で変更できます。既定値は20秒です。
- キューの内容はChromeのローカルストレージ（端末内の保存領域）へ保存されます。
